# HTTP API

All browser API requests use `/api`. JSON bodies and bearer authentication except login. OpenAPI is generated by Springdoc at backend `/v3/api-docs` and `/swagger-ui/index.html`; these need the bearer header (use curl or an authenticated API client). To access locally, run the development backend on 8080 or add a loopback-only Compose override. Do not publicly expose management ports.

```bash
curl -X POST http://localhost:3000/api/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"operator@seatlock.local","password":"SeatLock-demo-2026!"}'
# Copy the token into TOKEN (PowerShell: $env:TOKEN="...")
curl http://localhost:3000/api/events -H "Authorization: Bearer $TOKEN"
curl http://localhost:3000/api/events/EVENT_UUID -H "Authorization: Bearer $TOKEN"
curl -X POST http://localhost:3000/api/holds -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"eventId":"EVENT_UUID","seats":["C4"]}'
curl -X POST http://localhost:3000/api/checkout -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"holdId":"HOLD_UUID","key":"demo-checkout-0001","mode":"SUCCESS"}'
curl http://localhost:3000/api/bookings -H "Authorization: Bearer $TOKEN"
```

On Windows use `curl.exe` (PowerShell's older `curl` alias has different syntax) or Invoke-RestMethod with ConvertTo-Json.

| Method | Path | Access / purpose |
|---|---|---|
| POST | /auth/login | Email/password → opaque token + role |
| POST | /auth/logout | Revoke current token |
| GET | /events | Ordinary events, excluding lab data |
| GET | /events/{id} | Consistent seat snapshot, version, DB serverTime |
| GET | /events/{id}/stream | SSE snapshots, Authorization header required |
| GET | /holds | Current owner's active unexpired holds |
| POST | /holds | `{eventId,seats}`; maximum 6 distinct labels |
| DELETE | /holds/{id} | Owner-only explicit release |
| POST | /checkout | `{holdId,key,mode}`; key length 8–100 |
| GET | /checkout/{id} | Owner-only persisted result |
| GET | /bookings | Current owner's booking history and details |
| POST | /ops/events | Operator/admin create `{title,description,rows,cols,price}` |
| PUT | /ops/events/{id} | Edit, block resize if any reservation history |
| GET | /ops/reservations?event=UUID | Sanitized latest 100 holds/bookings |
| GET | /logs?before=ID&operation=HOLD&outcome=SUCCESS&event=UUID | Filtered 50-row cursor pagination |
| POST | /lab | `{scenario,attempts,concurrency}`; 2–300, 1–24 |
| GET | /lab | Latest 20 persisted jobs |
| POST | /lab/{id}/cancel | Cooperative cancellation; in-flight calls finish |
| GET | /lab/{id}/report | Export persisted job + measured results |

Modes: SUCCESS, DECLINE, DELAY (2 seconds), TIMEOUT (3 seconds), DUPLICATE (same callback twice), LATE (configured hold duration + 1 second). Retries with same key and same mode return persisted result, including PENDING. Different mode needs a new key. A late mode can take over five minutes in the default configuration; this is intentional.

Structured domain errors: `{code,message}`. 400 invalid request/seats/checkout; 401 invalid credentials; 404 nonexistent/private resource or invalid seat; 409 SEAT_HELD, SEAT_BOOKED, HOLD_EXPIRED, ACTIVE_HOLD_LIMIT, IDEMPOTENCY_CONFLICT, INVALID_TRANSITION, LAYOUT_HAS_RESERVATIONS, LAB_BUSY; 429 RATE_LIMIT; 503 RETRY_TRANSACTION / RATE_LIMIT_UNAVAILABLE. Framework auth denials may use Spring's standard error body. X-Correlation-ID accompanies requests. No raw SQL error is returned.

Operator and admin currently share all operational permissions. User cannot run lab jobs or edit catalogue/layouts.
